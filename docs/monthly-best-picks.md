# 월별 베스트 10 — 사진 전문가 기준

범위: 이미 복사된 `YYYY-MM` 폴더 안의 **사진만**. 원본은 건드리지 않는다. 영상·기타파일·문서는 랭킹에서 제외한다. 출력은 폴더당 약 10장 + 한국어 이유.

## 파이프라인

1. **게이트(탈락)** — 기술적으로 못 쓰는 컷을 먼저 뺀다.
2. **장르 판별** — 인물·풍경·거리·음식·반려동물·행사·건축 등. 문서/스크린샷은 탈락.
3. **보편 점수** — 기술(craft) + 구도(composition) + 순간(moment).
4. **장르 가중** — 장르마다 같은 기준의 비중을 바꾼다.
5. **유저 특징** — 자연어 요구(“웃는 아이”, “노을”, “단체”)를 필터·가산점으로 반영.
6. **다양성** — 연사 중복·같은 장면 반복을 깎고 10장을 고른다.
7. **설명** — 순위마다 이긴 기준 2~3개를 문장으로 붙인다.

기본 식 (구현 시 `src/services`에 둔다):

`score = 0.35·기술 + 0.25·구도 + 0.20·장르적합 + 0.20·유저특징`  
그다음 MMR식으로 유사 컷을 밀어낸다.

---

## 1. 게이트 — 무조건 탈락

| 기준 | 전문가 판단 | 감지 힌트 |
|---|---|---|
| 초점 실패 | 주제가 흐리다 | 라플라시안/그래디언트 분산 |
| 눈 감김 | 인물 메인인데 양쪽 눈 감김 | 얼굴 랜드마크 |
| 노출 붕괴 | 하이라이트 올화이트 또는 그림자만 | 히스토그램 클리핑 |
| 극단 노이즈 | 고감도 모래알, 디테일 없음 | ISO·고주파 노이즈 |
| 해상도 부족 | 크롭하면 못 씀 | 짧은 변 픽셀 |
| 기울어진 수평선 | 풍경인데 수평이 많이 기울음 | 소벨/소실점 |
| 문서·영수증·캡처 | “좋은 사진”이 아님 | 텍스트 밀도, 화면 비율 |
| 손가림·손가락 | 렌즈를 가림 | 가장자리 살색 블롭 |

연사 중 한 장만 남긴다(해시·시각 유사도). 의도적 모션블러·실루엣은 게이트를 통과시키고 장르 점수로 살린다.

---

## 2. 보편 기준 — 모든 장르에 적용

사진 교육·심사에서 반복되는 축이다. 점수는 0~1, 설명 문장의 재료가 된다.

### A. 기술 (Craft)

| ID | 기준 | 좋은 사진 | 감점 |
|---|---|---|---|
| A1 | 초점 | 주제 눈·전면이 맞음 | 뒷배경만 선명 |
| A2 | 노출 | 주제 톤이 읽힘 | 얼굴 날아감, 실루엣만(의도 제외) |
| A3 | 다이내믹 레인지 | 하이라이트·섀도 둘 다 정보 | 하늘 화이트홀 |
| A4 | 색 | WB 자연, 캐스트 없음 | 형광 녹색, 과한 비네트 |
| A5 | 노이즈 | 디테일 유지 | 뭉개진 NR, 컬러 노이즈 |
| A6 | 광학 | 왜곡·색수차 적음 | 광각 가장자리 사람 늘어남 |

### B. 구도 (Composition)

| ID | 기준 | 출처·실무 |
|---|---|---|
| B1 | 삼분할·황금비 | 주제가 교차점 근처. 중앙도 “대칭·초상”이면 가점 |
| B2 | 시각적 균형 | 무게(명암·면적)가 한쪽으로만 쏠리지 않음 |
| B3 | 유도선 | 길·난간·시선이 주제로 흐름 |
| B4 | 프레임 속 프레임 | 문·나뭇가지·창 |
| B5 | 여백 | 시선 방향에 숨 쉴 공간(look space) |
| B6 | 깊이 | 전경–중경–원경 층 |
| B7 | 가장자리 정리 | 잘린 관절·잘린 크라운·쓰레기 코너 없음 |
| B8 | 단순화 | 산만한 배경, 겹친 전봇대·머리 위 막대기 감점 |

### C. 순간·이야기 (Moment)

| ID | 기준 | 설명 |
|---|---|---|
| C1 | 결정적 순간 | 제스처·점프·시선 교환의 피크 |
| C2 | 감정 | 웃음·긴장·고요가 읽힘 |
| C3 | 빛 | 측광·역광 림라이트·골든아워. 정오 탑라이트는 인물 감점 |
| C4 | 색 조화 | 보색·유사색, 한 가지 강조색 |
| C5 | 고유성 | 그 달·그 장소에서만 나올 컷 (여행의 sense of place) |

---

## 3. 장르별 선택 기준 (가중)

숫자는 장르 적합 점수 안의 상대 비중(합 100). 유저가 장르를 고르면 그 행만 쓰고, 안 고르면 자동 장르 후 해당 행을 적용한다.

| 장르 | 최우선 | 비중 힌트 | 감점·주의 |
|---|---|---|---|
| **인물(개인)** | 눈 선명, 캐치라이트, 자연스러운 표정, 머리 위 여백 | 눈·표정 40 / 빛(렘브란트·루프·역광) 25 / 구도 20 / 피부톤 15 | 강제 미소, 팔짱만, 이중 턱 왜곡, 광각 근접 |
| **그룹** | 전원 눈 뜸, 키 맞춤, 상호작용 | 전원 상태 45 / 배치(삼각형·층) 25 / 순간 20 / 배경 10 | 한 명만 깜빡, 누가 누구인지 안 보임 |
| **풍경** | 수평, 전경 앵커, 하늘의 흥미, 빛의 시간대 | 빛·대기 35 / 깊이·전경 25 / 수평·선 20 / 날씨 드라마 20 | 기울어진 수평, 텅 빈 중경, 정오 평면광 |
| **도시·거리** | 레이어, 결정적 순간, 이야기 | 순간 40 / 층·타이밍 30 / 기하 20 / 노출(하이키 제외) 10 | 무단 근접으로 일그러진 얼굴, 의미 없는 등짝 |
| **음식** | 질감, 45° 또는 탑다운의 의도, 신선함 | 질감·광택 40 / 스타일링 25 / DoF 20 / 색 15 | 번진 소스, 지저분한 가장자리, 과한 광각 |
| **반려동물** | 눈 맞춤, 귀·수염 디테일, 캐치라이트 | 눈 45 / 순간(점프·하품) 30 / 배경 분리 15 / 털 질감 10 | 코만 큰 광각, 빨간 눈 |
| **아이·가족 행사** | 관계(안기·보기), 핵심 인물, 장소 맥락 | 관계 40 / 표정 25 / 이야기 20 / 기술 15 | 뒷모습만, 케이크에 가린 얼굴 |
| **건축·인테리어** | 수직선, 대칭, 왜곡 제어 | 선·대칭 40 / 빛(창호) 25 / 정리된 공간 20 / 색 15 | 기울어진 벽, 난잡한 전선 |
| **야경·천체** | 점광원(별·가로등)이 점이지 선이 아님, 노이즈 | 점광·별 35 / 노출 30 / 전경 실루엣 20 / 노이즈 15 | 카메라 흔들림, 빛번짐만 |
| **매크로** | 초점면, 배경 멜트, 주제 스케일 | 초점면 50 / 배경 25 / 안정 15 / 조명 10 | 초점 뒤 날아간 눈(곤충) |
| **스포츠·액션** | 피크 동작, 얼굴, 공/라켓이 프레임 안 | 피크 40 / 얼굴 25 / 셔터(동결 vs 패닝) 20 / 배경 15 | 공 잘림, 등만 |
| **여행** | 장소가 읽힘 + 사람 또는 상징 | 장소성 35 / 사람·스케일 25 / 빛 20 / 구도 20 | 아무 벽이나, GPS만 다른 중복 |

장르 신뢰도가 낮으면 보편 점수(A+B+C)만 쓰고, 설명에 장르를 단정하지 않는다.

## 4. 유저가 요구하는 특징

유저 문장은 **하드 필터**와 **소프트 가산**으로 나눈다.

| 유형 | 예 | 처리 |
|---|---|---|
| 피사체 | 아이, 강아지, 바다, 음식 | 탐지 실패 컷은 10장 후보에서 제외(하드) |
| 속성 | 웃는, 단체, 노을, 비, 실내 | 속성 점수로 가산(소프트) |
| 색·소품 | 빨간 옷, 모자, 케이크 | CLIP/태그 유사도 |
| 부정 | 문서 빼, 셀카 빼 | 해당 클래스 감점 또는 제외 |
| 인원 | 혼자 / 둘 / 여러 명 | 얼굴 수 |

유저 문장이 비어 있으면 장르 자동 + 보편 베스트만. 매칭이 약하면 순위를 채우되 이유에 “요청 특징은 약함”을 명시한다. 억지로 10장을 채우려고 게이트 탈락 컷을 올리지 않는다(그달은 7장일 수 있다).

---

## 5. 다양성 (10장이 같은 연사가 되지 않게)

- 시각 유사도(pHash/임베딩)가 높은 버스트는 최고점 1장만.
- 같은 장소·같은 구도가 연속이면 두 번째부터 감점.
- 가능하면 장르·거리(근경/원경)·실내외를 섞되, 유저가 “아이만”이면 섞지 않는다.
- 인물 메인이면 동일 인물 독점을 조금 허용하되, 10장 전부 같은 얼굴·같은 각도는 피한다.

---

## 6. 이유 문장 규칙

각 순위는 **사실 기준 ID**에서만 문장을 만든다. 추측(“행복해 보여요”) 금지, 관측(“눈이 맞고, 창쪽 측광이 볼 윤곽을 살림”) 허용.

형식: `1위 · 인물 · 눈 초점(A1), 측광(C3), 요청 “웃음” 일치`

구현 시 파일명·경로는 `escapeHtml` 후 모달에 넣는다.

---

## 7. 하지 않을 것

- 원본 이동·삭제·덮어쓰기. 랭킹은 복사본 폴더의 **표시**다.
- 미분류/기타파일 폴더를 베스트 대상으로 쓰지 않는다(월 폴더만).
- 유저 얼굴·사진을 클라우드로 보내는 기능은 동의 체크 후에만. 원본이 아니라 축소 JPEG만 Google Gemini로 보낸다. 키는 `process.env` / `.env`.
- 미구현 모델을 코드에 가짜 점수로 넣지 않는다.
